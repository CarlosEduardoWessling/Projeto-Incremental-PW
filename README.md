**Aluno:** Carlos Eduardo Wessling  
**Disciplina:** Programação para Web 1

## Objetivo
Desenvolver um site pessoal de maneira incremental, aplicando os conhecimentos adquiridos em HTML e CSS. O mesmo repositório é atualizado ao longo das etapas, mantendo o histórico das versões no Git.

## Etapas do projeto

### Incremento 1 — HTML puro
Criação da estrutura e do conteúdo da página, incluindo apresentação, foto, seção Sobre mim, formação acadêmica, projetos e interesses, habilidades, links para perfis e formulário de contato demonstrativo.

### Incremento 2 — CSS
Estilização da mesma página com um arquivo CSS externo, aplicando cores, tipografia, espaçamentos, bordas, organização visual das seções e efeitos `hover` em links e botões.

### Incremento 3 — Mobile First
Adaptação do layout para diferentes tamanhos de tela, começando pelo celular e utilizando Flexbox, Grid e `media queries` para tablet e desktop.

**Larguras previstas para validação:** 375 px (celular), 768 px (tablet) e 1200 px (desktop).
